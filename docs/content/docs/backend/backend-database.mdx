# 数据存储

网页版全静态，没有服务端数据库。原 Go Hub（`backend/`：账号、提示词包、R2 上传，PostgreSQL + GORM）已删除，回滚点为 git tag `go-backend-final`。

- 浏览器：工程、素材、提示词、自定义工作流模板（`iris_custom_templates_v1`）、Agent 动态面板（`iris_hark_panels_v1`）、项目长效记忆（`agent-memory`）、后台任务台账（`iris_agent_tasks_v1`）与 API Key 均存在本机 localforage / IndexedDB，localStorage 只放极小配置。
- 线上 Cloudflare Worker（`worker/index.ts`）无状态，只做 `/api/llm-proxy/*` 同源 CORS 转发，不存任何数据。

## 本机 Agent 视频流水线存储

Agent 视频流水线的 trace 存在用户本机，不经过任何服务端，也不同步到云端。它与桌面 Production Runtime 共用同一个 `flovart-state.db`（`<app_data_dir>/flovart-state.db`，identifier `com.flovart.desktop`），表由 migration 5（`tools/iris/contracts/runtime/migrations/0005_agent_pipeline.sql`）建立：Rust `RuntimeStore` 和 Node `tools/iris/pipeline/store.js` 执行同一份 SQL，并共用 `runtime_migrations` 账本。Node pipeline 边界是唯一写入方；Rust Runtime 只通过 `pipeline.run.get` 读取，返回与 Node `Pipeline.trace()` 相同的 JSON（`npm run e2e:pipeline:parity` 校验）。产物文件放在 `<app_data_dir>/pipeline/`；`IRIS_PIPELINE_HOME` 可把数据库和产物一起改到指定目录（测试与隔离用）。

| 表 | 用途 | 关键字段 |
| --- | --- | --- |
| `pipeline_runs` | 一次制作 run | `id`、`project_id`、`status`（active / blocked / passed / archived / stopped）、`budget_json`、`blocker_json`、`head_version` |
| `run_steps` | 命令边界自动记录的 Step | `run_id` + `seq` 唯一；`tool`、`caller`、`mutation_id`（`run_id, tool, mutation_id` 唯一）、`args_digest`、`status`、`attempts`、`artifact_ids_json` |
| `pipeline_artifacts` | 内容寻址产物 | `sha256`、`kind`、`path`、`media_json`、`params_json`、`rejected` |
| `pipeline_spec_versions` | 合成 spec 修订 | 主键 `run_id, version`；`parent_version`、`spec_sha256`、`diff_json` |
| `pipeline_renders` | 每个版本的渲染 | `version`、`preset`（still / draft / final）、`engine`、`artifact_id`、`probe_json` |
| `review_rounds` | 评审轮 | `run_id, round` 唯一；`reviewer`、`caller`、`verdict`、`findings_json`、`fixed_by_version` |
| `pipeline_usage_ledger` | run 级预算账本 | `entry_kind`（reserve / confirm / release）、`amount_micros`、`tasks` |
